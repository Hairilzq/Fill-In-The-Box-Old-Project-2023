# Fill in the Box! Ver 4.0 - Old School Project
This was an Old Computing project that I made back in late-2023, when I was in Secondary 3. My teacher had originally instructed for us to create a project using our knowledge on Python programming that is:

- A: Educational
- B: Fun and Interactive

Given my limited knowledge on Python at the time, I decided to develop a puzzle game using Pygame. The core premise is that you have to fill up a box using a set of given items. The box has a limited size capacity which is a quantifiable number, which you then fill up with items that each have their own variable sizes. Some items like an 'Eraser' or 'Pencil' are smaller in size and occupy less space in the box, while items like 'Microwave' or 'Clock' are bigger in size and occupy more space. The goal is to fill the box perfectly so that the items occupy the 'exact' amount of space in the box. 

The items generally follow a standard size range, for example, a 'Pencil' occupies somewhere around 1-3 spaces. The script randomly decides what amount of space the pencil occupies each game, so you have to adapt to this fact. Also, there are other restrictions, such as filling the box with a maximum of 5 total items. Adding more than that will require you to remove an item, same for when the box is filled over the max size capacity. The max size capacity also changes each game.

The game also features some other game modes. The main gamemode is 'Endless', where you play game after game endlessly. There is also a 'Speedrun' gamemode where you play 5 levels back-to-back, trying to complete them as quickly as possible. Lastly, the game also features a 'Hardmode' where there are added requirements (Like weight, cost) that you need to meet. After playtesting it back then, this gamemode is generally playable and it is quite rare to be unable to meet a solution
